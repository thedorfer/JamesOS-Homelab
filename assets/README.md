# Assets

The `assets/` directory is reserved for public-safe diagrams, screenshots, and images used in documentation.

## Allowed

- sanitized architecture diagrams
- screenshots with no tokens or private information
- public logos created for JamesOS-Homelab
- public documentation images

## Not Allowed

Do not commit:

- screenshots containing tokens, secrets, or account IDs
- screenshots showing private family data
- screenshots showing full Cloudflare tunnel credentials
- screenshots showing password managers or recovery codes
- raw incident evidence
