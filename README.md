# JamesOS Homelab

JamesOS Homelab is the Infrastructure-as-Code repository powering the JamesOS platform.

This repository documents, deploys, secures, and maintains my complete self-hosted infrastructure.

## Current Services

- WordPress
- Nextcloud
- Open WebUI
- Cloudflare Tunnel
- Raspberry Pi Gateway

## Goals

- Infrastructure as Code
- Security First
- Disaster Recovery
- Automated Backups
- Local AI
- Personal Cloud
- Enterprise-grade Documentation

## Repository Structure

docs/
Architecture, recovery, security and operational documentation.

docker/
Docker compose stacks.

scripts/
Automation and maintenance.

services/
Service-specific documentation.

cloudflare/
DNS, Tunnel and WAF configuration.
